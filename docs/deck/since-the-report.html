MCP and remote tasks23

A repo agent that reads the code

/github-crawl clones the repo and digs through it the way you would, then answers with path:line citations.

  1. Cloneinto a temp folder, kept 30 minutes for follow-ups
  2. Start where you werea file, a folder, a branch or a commit URL
  3. Searchripgrep for the names in the question
  4. Readonly the lines around each hit
  5. Answerwith path:line for every claim

A shell it can't misuse

Read-only programs only: rg, grep, find, sed -n, git log
No redirects, no ; or &&, no $( )
No paths outside the clone, symlinks checked out as files
No find -exec, rg --pre, sed -i or git -c

3. DatabasesPostgres, Neo4j and OpenSearch, waited on
4. Builddependencies and the extension
5. Backendat login (launchd or systemd) or just for now
6. Browsersfinds them, guides the load, confirms it connected
7. MCPregisters the tools with your coding agents
